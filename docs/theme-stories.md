# Theme Stories

このメモは、各テーマのストーリーと世界観の芯を毎回思い出せるようにするための記録です。
新規カードを追加する時は、まずここを見て「そのテーマの何を描くべきか」を確認します。
内容は固定設定ではなく、カード追加時に少しずつ補強・追記して構いません。

## 共通ルール

- テーマカードのイラストは、効果図解より先にテーマの物語を伝える。
- 同テーマ内では、色・建築・道具・衣装・感情の方向性を揃える。
- ただしキャラクター同士の顔、年齢感、役割、シルエットは分ける。
- 新規カード追加時にストーリーを少し広げてもよいが、既存カードの空気を壊さない。
- 汎用カードは世界観より機能優先でもよいが、全体の見た目から極端に浮かないようにする。

## 星導

- Story core:
  - 星導は、星の軌道と記録を読み解いて未来の航路を開く観測文明。
  - カードの力は「星図」「航路」「再点火」「軌道制御」として表れる。
  - 失われた記録や途切れた星路をつなぎ直し、静かに優勢を築くテーマ。
- Visual anchors:
  - 深い群青、青白い光、金の星図線、白い神殿遺跡、天球儀、浮遊する星片。
  - 清潔で神秘的、静かな緊張感、夜空と古代観測施設。
- Character guidance:
  - 観測者、案内役、祈り手、衛士など、役職が見た目でわかるようにする。
  - 顔立ちは似せすぎず、知性派、祈祷者、護衛役で表情と装備を変える。
- Card addition guidance:
  - 単なる星空イラストではなく、「何を導き、何を再接続しているか」を場面で見せる。
  - `star_navigator` は航路士本人の役割が主役。
  - `star_chart` は人物より星図儀式や帰還航路そのものを主役にしやすい。
- Current story extension:
  - アステルは散逸した星図断片を回収し、失われた星導航路を再接続する若い航路士。
  - 帰還航路は墓地に沈んだ記録を再び星導の力として循環させる儀式。

## 黒機

- Story core:
  - 黒機は、重工業と殲滅兵装で押し潰す軍事機械勢力。
  - 盤面の制圧と継続砲撃で相手の行動を奪い、圧力を積み上げる。
- Visual anchors:
  - 黒鉄、赤熱, 煤、重砲身、巨大ギア、工場炉、要塞設備。
  - 鈍重だが止まらない、戦争機械の質量感。
- Character guidance:
  - 人型兵器でも人格より兵装や型番感を優先。
  - 一枚絵の主役は「機械の重量」や「砲火」で見せる。
- Card addition guidance:
  - スピード感より圧殺感。
  - 破壊、拘束、砲撃、重圧をどう絵にするかを優先。

## 断刃

- Story core:
  - 断刃は、相手の隙と行動の乱れを見抜き、刻印し、処刑へつなぐ執行集団。
  - 行動済みや拘束状態を「狩りの印」として扱う美学がある。
- Visual anchors:
  - 黒、灰、鈍い赤、処刑台、鎖、刻印、細身の刃、法執行にも見える装束。
  - 静かな残酷さ、判断の速さ、処断の儀式性。
- Character guidance:
  - 追跡者、刻印士、処刑人、裁断者で武器と姿勢を分ける。
  - 同じ暗色系でも、偵察型・執行型・統率型でシルエット差を出す。
- Card addition guidance:
  - 「切る瞬間」だけでなく、追い詰める前段階の空気も大事にする。
  - 状態異常や執行準備をどう視覚化するかを考える。

## 電脳

- Story core:
  - 電脳は、学園生活の表面の裏でネットワークと情報優位を握る高速展開テーマ。
  - 追加召喚、侵入、公開、カウンターハックは、情報戦と接続の速さとして表れる。
- Visual anchors:
  - シアン、白、黒、ネオン、UI、校内ネット、端末、仮想空間の層。
  - 学園とサイバー空間が重なって見える画面づくり。
- Character guidance:
  - 生徒会、委員長、ハッカー、ランナーなど、役職と性格を顔で分ける。
  - 同テーマ内でも、優等生系、奔放系、冷静系で髪型や視線を変える。
- Card addition guidance:
  - ただのサイバー背景では弱い。
  - 「誰がどこに侵入し、何を暴いたか」が絵から読める方がよい。

## 双彩

- Story core:
  - 双彩は、二人組の関係性そのものが力になる配信・ステージ系テーマ。
  - ペアがそろった時に真価を出すので、カードごとに関係性の温度が重要。
- Visual anchors:
  - ステージ照明、ポップ色、プリズム、配信空間、アイドル/パフォーマンス演出。
  - 楽しさだけでなく、息の合った連携や信頼も見せる。
- Character guidance:
  - ペアごとに関係性を分ける。
  - ヒカリ＆ミントは明快さ、ネネ＆ルリは駆け引き、ココ＆ルナは勢い、のように温度差をつける。
- Card addition guidance:
  - 単独キャラ絵でも「相方の存在を感じる」構図にするとテーマらしさが増す。
  - ステージや配信機材は物語の背景であって、主役はペアの関係性。

## 汎用

- Story core:
  - 汎用カードは特定テーマに属さない現場道具、兵士、装置、即席判断。
  - 世界観の隙間を埋める存在で、過度な固有神話は持たせない。
- Visual anchors:
  - 戦場、倉庫、作戦卓、標準装備、記号的にわかりやすい構図。
- Card addition guidance:
  - 強すぎる固有キャラ性は避ける。
  - どのテーマにも混ざれる「道具感」や「標準技術感」があると使いやすい。

## Update Process

- 新しいテーマを作ったら、このファイルに以下を追加する:
  - Story core
  - Visual anchors
  - Character guidance
  - Card addition guidance
- 既存テーマに新規カードを足した時は、必要なら `Current story extension` を追記する。
- イラスト生成前に、このファイルの該当テーマを読み返してからプロンプトを書く。
